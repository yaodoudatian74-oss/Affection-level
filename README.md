# OMEGA AI WORLD

AIエージェントたちの成長と共同制作を見守る、日本語対応のレスポンシブなWebアプリです。

## Stage 01 — 基本UIとアプリの土台

現在の段階では、アプリの操作可能なUI基盤を実装しています。

- PC・Androidスマートフォンに対応したレスポンシブなダッシュボード
- 10体の初期AIエージェントと役割・レベル・稼働状態の表示
- エージェント名・役割・状態の検索
- サイドナビゲーションと今後の機能の案内
- ダーク／ライトテーマ切替（選択をブラウザーの `localStorage` に保存）
- 日本語の日付表示、モバイルメニュー、キーボードショートカット（⌘K / Ctrl+K）

## 起動方法

ビルドツールや依存パッケージは不要です。`index.html` をブラウザーで開くか、このリポジトリを GitHub Pages などの静的ホスティングに公開してください。

## 現在の制限

この段階ではAIモデル/APIへの接続、エージェントの会話・編集、チーム制作、成長データの保存は実装していません。画面上のサンプル活動やステータスはデモ表示です。機能を実装済みと誤認させないよう、未実装の操作は今後の開発段階で追加予定であることを表示しています。

## 次の段階

エージェント管理とデータモデル、続いてXP・レベル・関係性の保存機能を順番に追加していきます。APIキーをブラウザーに埋め込むことはせず、モデル連携を実装する段階では安全なサーバーサイド構成を選定します。
